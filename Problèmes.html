Problèmes Mathématiques

🟢 Niveau Facile

Problème 1 :
Montrer que : 1 + 2 + ... + n = n(n+1)/2

Difficulté : ★☆☆☆☆

On peut associer les termes : (1+n), (2+n-1), etc. Chaque paire vaut n+1. Il y a n/2 paires → somme = n(n+1)/2.

🟡 Niveau Intermédiaire

Problème 2 :
Calculer la somme des carrés : 1² + 2² + ... + n²

Difficulté : ★★☆☆☆

La formule est : n(n+1)(2n+1)/6. Elle se démontre par récurrence ou méthodes classiques.

🔴 Niveau Avancé (IMC / Olympiades)

Problème 3 :
Trouver tous les entiers n tels que n² + n + 1 soit premier.

Difficulté : ★★★★☆

On teste plusieurs valeurs. Pour n ≥ 2, l'expression devient souvent composée. Les cas particuliers donnent les solutions. (À compléter avec une vraie démonstration détaillée)

Problème 4 : (Problème de Josephus)

Dans le royaume fictif de Sikinia, les condamnés à mort sont placés en cercle et numérotés de 1 à n. En commençant par le numéro 2, un prisonnier sur deux est éliminé successivement, en suivant le cercle, jusqu’à ce qu’il ne reste qu’un seul survivant.

Question : Pour un entier n donné, comment déterminer la position du survivant ?

Difficulté : ★★★★☆

Ce problème est connu sous le nom de problème de Josephus. Lorsque l’on élimine un élément sur deux, la position du survivant peut être déterminée en écrivant n sous la forme : n = 2^k + l où 2^k est la plus grande puissance de 2 inférieure ou égale à n. La position du survivant est alors : J(n) = 2l + 1 Cette formule peut être démontrée par récurrence ou en analysant la structure du processus d’élimination.

Advanced Mathematics Problems (IMC Level)

Problem 1 (Number Theory)
Prove that there are infinitely many primes of the form 4n + 3.
Suppose finitely many: p₁,...,pₖ. Consider N = 4(p₁...pₖ) - 1. Then N ≡ 3 mod 4. Any prime divisor q of N satisfies q ≡ 3 mod 4. But q is not among p₁,...,pₖ. Contradiction.
Problem 2 (Algebra)
Solve in reals: x⁴ - 5x² + 4 = 0.
Let y = x². Then y² -5y +4 = 0 → (y-1)(y-4)=0. So y=1 or 4 → x = ±1, ±2.
Problem 3 (Inequality)
For positive a,b,c prove: (a²+b²+c²) ≥ ab+bc+ca.
(a-b)²+(b-c)²+(c-a)² ≥ 0 → gives result.
Problem 4 (Combinatorics)
Number of ways to choose 2 elements from n?
C(n,2) = n(n-1)/2.
Problem 5 (Sequences)
Find limit of uₙ₊₁ = (uₙ + 3)/2.
Limit L satisfies L = (L+3)/2 → L = 3.
Problem 6 (Number Theory)
Prove 9 divides 10ⁿ - 1.
10 ≡ 1 mod 9 → 10ⁿ ≡ 1 → result.
Problem 7 (Function)
Find minimum of f(x)=x²-6x+5.
Vertex x=3 → f(3) = -4.
Problem 8 (Combinatorics)
How many subsets of size k from n?
C(n,k) = n! / (k!(n-k)!).
Problem 9 (Inequality)
Prove (a+b)/2 ≥ √(ab).
(√a - √b)² ≥ 0 → gives AM ≥ GM.
Problem 10 (Series)
Sum of geometric series ∑(k=0→n) r^k.
S = (1 - r^{n+1}) / (1 - r), r ≠ 1.

Advanced IMC / Putnam-Level Problems

Problem 1 (Number Theory)
Prove that √2 is irrational.
Assume √2 = p/q in lowest terms. Then 2q² = p² → p even → p=2k. Substitute: 2q² = 4k² → q² = 2k² → q even. Contradiction since p,q not coprime.
Problem 2 (Combinatorics)
Count binary strings of length n with no consecutive 1s.
Let a_n be count. Either starts with 0 → a_{n-1}, or 10 → a_{n-2}. Thus a_n = a_{n-1} + a_{n-2} (Fibonacci).
Problem 3 (Algebra)
Find all real solutions of x³ - 3x + 1 = 0.
Use substitution x = 2cosθ → leads to trigonometric solution. Solutions: x = 2cos(2πk/9).
Problem 4 (Inequality)
For a,b,c > 0 prove: (a²+b²+c²)² ≥ 3(a³b + b³c + c³a)
Apply rearrangement inequality or homogenization + symmetry.
Problem 5 (Number Theory)
Show infinitely many primes.
Classic Euclid: product of primes +1 not divisible by any known prime.
Problem 6 (Analysis)
Compute limit: lim (1 + 1/n)^n
Standard limit defining e.
Problem 7 (Combinatorics)
Number of permutations with no fixed points.
Derangements: !n ≈ n!/e.
Problem 8 (Number Theory)
Prove that for any integer n, n³ - n is divisible by 6.
n(n-1)(n+1) product of 3 consecutive integers → divisible by 2 and 3.
Problem 9 (Algebra)
Find all f such that f(x+y)=f(x)+f(y).
Cauchy equation → linear if continuity assumed.
Problem 10 (Geometry)
Sum of angles in triangle.
π radians or 180°.
