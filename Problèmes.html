🟢 Fundamentals

Problème 1 :
Montrer que : \[ 1 + 2 + \cdots + n = \frac{n(n+1)}{2} \]
Difficulté : ★☆☆☆☆
Preuve 1 (méthode de Gauss)

On écrit la somme deux fois : \[ S = 1 + 2 + \cdots + n \] \[ S = n + (n-1) + \cdots + 1 \] En additionnant : \[ 2S = (n+1) + (n+1) + \cdots + (n+1) \] Il y a \(n\) termes : \[ 2S = n(n+1) \Rightarrow S = \frac{n(n+1)}{2} \] Preuve 2 (récurrence)

Initialisation : \(n=1\) → OK Hérédité : supposer vrai pour \(n\), montrer pour \(n+1\) \[ S_{n+1} = S_n + (n+1) \] \[ = \frac{n(n+1)}{2} + (n+1) = \frac{(n+1)(n+2)}{2} \] Donc vrai.

🟡 Intermediate

Problème 2 :
Calculer : \[ 1^2 + 2^2 + \cdots + n^2 \]
Difficulté : ★★☆☆☆
Résultat : \[ \frac{n(n+1)(2n+1)}{6} \] Preuve (récurrence)

On suppose vrai pour \(n\). \[ S_{n+1} = S_n + (n+1)^2 \] \[ = \frac{n(n+1)(2n+1)}{6} + (n+1)^2 \] Factorisation → donne : \[ \frac{(n+1)(n+2)(2n+3)}{6} \] Donc formule valide.

🔴 IMC Level

Problème 3 :
Trouver tous les entiers \(n\) tels que : \[ n^2 + n + 1 \] soit premier.
Difficulté : ★★★★☆
On étudie modulo 3 : \[ n \equiv 0,1,2 \mod 3 \] Cas 1 : \(n \equiv 1\) \[ n^2+n+1 \equiv 1+1+1 = 3 \equiv 0 \] Donc divisible par 3 → composé si >3. Donc seuls petits cas possibles. Test : \[ n=0 →1,\quad n=1→3,\quad n=2→7 \] Au-delà → composé. Conclusion : \(n=0,1,2\)

🔥 Putnam Level

Problème 4 :
Montrer que : \[ (a+b+c)\left(\frac{1}{a}+\frac{1}{b}+\frac{1}{c}\right) \ge 9 \]
Difficulté : ★★★★★
Développons : \[ = 3 + \sum \frac{a}{b} \] Or : \[ \frac{a}{b} + \frac{b}{a} \ge 2 \] Donc : \[ \sum \frac{a}{b} \ge 6 \] Conclusion : \[ ≥ 3 + 6 = 9 \]
