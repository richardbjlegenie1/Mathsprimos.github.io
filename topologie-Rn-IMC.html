Cours complet étape par étape — Du fondamental au niveau IMC

Sommaire
Introduction

Pourquoi la topologie à l'IMC ?

La topologie de \(\mathbb{R}^n\) constitue la colonne vertébrale de l'analyse moderne. À l'IMC, elle apparaît — souvent implicitement — dans presque tous les problèmes : compacité pour obtenir un extremum, connexité pour les arguments de chemin, complétude pour les suites de Cauchy.

⭐ Thèmes IMC fréquents liés à la topologie
  • Démontrer qu'une fonction continue sur un compact est bornée et atteint ses bornes
  • Utiliser la connexité pour montrer qu'une fonction est constante
  • Théorème du point fixe de Brouwer (en dimension 1 : cas intermédiaire)
  • Suites et compacité séquentielle (Bolzano–Weierstrass)
  • Ouverts, fermés et leurs propriétés dans des arguments d'analyse

Structure du cours

Ce cours est divisé en 7 étapes progressives, chacune construisant sur la précédente :

  1. La distance dans ℝⁿ — normes et espaces métriques
  2. Ouverts et fermés — la topologie standard
  3. Suites et limites — convergence et complétude
  4. Compacité — théorème de Heine–Borel
  5. Connexité — ensembles connexes et par arcs
  6. Continuité et topologie — caractérisations équivalentes
  7. Théorèmes majeurs IMC — applications directes
Convention
On travaille dans \(\mathbb{R}^n\) muni de la norme euclidienne \(\|x\| = \sqrt{x_1^2 + \cdots + x_n^2}\), sauf mention contraire. Toutes les normes sur \(\mathbb{R}^n\) étant équivalentes, les notions topologiques ne dépendent pas du choix de la norme.
Étape 1 / 7

La Distance dans ℝⁿ

1.1 Normes sur ℝⁿ

Définition — Norme
Une norme sur \(\mathbb{R}^n\) est une application \(\|\cdot\| : \mathbb{R}^n \to \mathbb{R}_+\) vérifiant :
  1. Séparation : \(\|x\| = 0 \Leftrightarrow x = 0\)
  2. Homogénéité : \(\|\lambda x\| = |\lambda|\,\|x\|\) pour tout \(\lambda \in \mathbb{R}\)
  3. Inégalité triangulaire : \(\|x + y\| \leq \|x\| + \|y\|\)
Exemples fondamentaux
Pour \(x = (x_1, \ldots, x_n) \in \mathbb{R}^n\) :
  • \(\|x\|_1 = \sum_{i=1}^n |x_i|\)   (norme \(L^1\))
  • \(\|x\|_2 = \left(\sum_{i=1}^n x_i^2\right)^{1/2}\)   (norme euclidienne)
  • \(\|x\|_\infty = \max_{1 \leq i \leq n} |x_i|\)   (norme du sup)

Relation : \(\|x\|_\infty \leq \|x\|_2 \leq \|x\|_1 \leq \sqrt{n}\,\|x\|_2 \leq n\,\|x\|_\infty\).

1.2 Distance et boules

Définition — Distance et boules
La distance entre \(x, y \in \mathbb{R}^n\) est \(d(x,y) = \|x - y\|\). On définit :
  • Boule ouverte : \(B(a,r) = \{x \in \mathbb{R}^n : \|x-a\| < r\}\)
  • Boule fermée : \(\bar{B}(a,r) = \{x \in \mathbb{R}^n : \|x-a\| \leq r\}\)
  • Sphère : \(S(a,r) = \{x \in \mathbb{R}^n : \|x-a\| = r\}\)

1.3 Équivalence des normes

Théorème fondamental — Équivalence des normes

Sur \(\mathbb{R}^n\), toutes les normes sont équivalentes : pour deux normes \(\|\cdot\|_\alpha\) et \(\|\cdot\|_\beta\), il existe \(c, C > 0\) tels que pour tout \(x \in \mathbb{R}^n\) :

\[ c\,\|x\|_\alpha \leq \|x\|_\beta \leq C\,\|x\|_\alpha \]
Idée de preuve

Il suffit de montrer que toute norme \(\|\cdot\|\) est équivalente à \(\|\cdot\|_1\). Soit \((e_i)\) la base canonique. Par homogénéité et triangulaire : \(\|x\| \leq M\|x\|_1\) avec \(M = \max_i \|e_i\|\). Pour la minoration, on utilise la compacité de la sphère unité \(\{x : \|x\|_1 = 1\}\) et la continuité de \(\|\cdot\|\) (qui est lipschitzienne pour \(\|\cdot\|_1\)), donc \(\|\cdot\|\) atteint son minimum \(m > 0\).

□
⭐ Conséquence IMC cruciale

Puisque les normes sont équivalentes, les notions de suite convergente, ensemble ouvert/fermé, compact, connexe et fonction continue sont les mêmes pour toutes les normes. On peut donc choisir la norme la plus commode pour chaque problème !

Exercices
Ex 1.1 Montrer que \(\|x\|_\infty \leq \|x\|_2 \leq \sqrt{n}\,\|x\|_\infty\) pour tout \(x \in \mathbb{R}^n\). ▼
Indice : Pour la première inégalité, remarquer que \(\max|x_i|^2 \leq \sum x_i^2\). Pour la seconde, \(\sum x_i^2 \leq n \max x_i^2\).
Ex 1.2 Décrire géométriquement les boules unités \(B(0,1)\) pour \(\|\cdot\|_1\), \(\|\cdot\|_2\), \(\|\cdot\|_\infty\) dans \(\mathbb{R}^2\). ▼
Indice : \(\|\cdot\|_1\) donne un carré tourné à 45°, \(\|\cdot\|_2\) un disque, \(\|\cdot\|_\infty\) un carré aligné aux axes.
Étape 2 / 7

Ouverts et Fermés

2.1 Définitions fondamentales

Définition — Ensemble ouvert
\(U \subseteq \mathbb{R}^n\) est ouvert si pour tout \(x \in U\), il existe \(r > 0\) tel que \(B(x, r) \subseteq U\).

Intuition : tout point de \(U\) admet un "voisinage" entièrement dans \(U\).

Définition — Ensemble fermé
\(F \subseteq \mathbb{R}^n\) est fermé si son complémentaire \(\mathbb{R}^n \setminus F\) est ouvert.

Équivalent : \(F\) contient toutes ses valeurs d'adhérence, i.e., si \((x_k) \subseteq F\) et \(x_k \to x\), alors \(x \in F\).

⚠ Piège classique à l'IMC
Un ensemble peut être ni ouvert ni fermé (ex : \([0,1[\)), ou les deux à la fois (clopen : \(\emptyset\) et \(\mathbb{R}^n\)). "Non fermé" ne signifie pas "ouvert" !

2.2 Propriétés des ouverts et fermés

Théorème — Stabilité par unions et intersections
  • Union quelconque d'ouverts est ouverte.
  • Intersection finie d'ouverts est ouverte.
  • Intersection quelconque de fermés est fermée.
  • Union finie de fermés est fermée.

Contre-exemple : \(\bigcap_{n=1}^\infty \left(-\frac{1}{n}, \frac{1}{n}\right) = \{0\}\) fermé, intersection d'ouverts.

2.3 Intérieur, adhérence, frontière

Définition — Intérieur, adhérence, frontière
Pour \(A \subseteq \mathbb{R}^n\) :
  • \(\mathring{A} = \text{int}(A)\) : le plus grand ouvert contenu dans \(A\) (union de tous les ouverts \(\subseteq A\))
  • \(\bar{A} = \text{adh}(A)\) : le plus petit fermé contenant \(A\) (intersection de tous les fermés \(\supseteq A\))
  • \(\partial A = \bar{A} \setminus \mathring{A}\) : la frontière de \(A\)

Caractérisation : \(x \in \bar{A} \Leftrightarrow \forall r > 0,\; B(x,r) \cap A \neq \emptyset\).

Exemple — Calculons pour \(A = B(0,1)\) dans \(\mathbb{R}^2\)
  • \(\mathring{A} = B(0,1)\) (déjà ouvert)
  • \(\bar{A} = \bar{B}(0,1)\) (disque fermé)
  • \(\partial A = S(0,1)\) (cercle unité)

Pour \(A = \mathbb{Q}^n\) : \(\mathring{A} = \emptyset\), \(\bar{A} = \mathbb{R}^n\), \(\partial A = \mathbb{R}^n\).

2.4 Points d'accumulation et ensemble dérivé

Définition — Point d'accumulation
\(x\) est un point d'accumulation (ou point limite) de \(A\) si toute boule \(B(x,r)\) contient un point de \(A\) distinct de \(x\). L'ensemble des points d'accumulation est noté \(A'\).

On a : \(\bar{A} = A \cup A'\).

⭐ Technique IMC — Montrer qu'un ensemble est fermé

La méthode la plus efficace : prendre une suite \((x_k)\) dans l'ensemble qui converge, et montrer que sa limite est encore dans l'ensemble. C'est la caractérisation séquentielle des fermés.

Exemple type : \(F = \{(x,y) \in \mathbb{R}^2 : xy \geq 1\}\) est fermé car \(f(x,y) = xy\) est continue et \(F = f^{-1}([1,+\infty))\).

Exercices
Ex 2.1 Montrer que \(\text{GL}_n(\mathbb{R})\) (matrices inversibles) est ouvert dans \(\mathcal{M}_n(\mathbb{R}) \cong \mathbb{R}^{n^2}\). ▼
Indice : \(\text{GL}_n(\mathbb{R}) = \{M : \det(M) \neq 0\} = (\det)^{-1}(\mathbb{R}^*)\). Le déterminant est un polynôme, donc continu. L'image réciproque d'un ouvert par une application continue est ouverte. (Ce problème apparaît régulièrement à l'IMC !)
Ex 2.2 ★ (style IMC) Soit \(A \subseteq \mathbb{R}^n\). Montrer que \(\partial(\partial A) \subseteq \partial A\). ▼
Indice : \(\partial A\) est toujours un fermé (car \(\partial A = \bar{A} \cap \overline{\mathbb{R}^n \setminus A}\), intersection de deux fermés). Pour un fermé \(F\), on a \(\partial F \subseteq F\) (car \(\partial F \subseteq \bar{F} = F\)).
Étape 3 / 7

Suites, Limites et Complétude

3.1 Convergence dans ℝⁿ

Définition — Suite convergente
Une suite \((x_k)_{k \geq 1}\) dans \(\mathbb{R}^n\) converge vers \(\ell \in \mathbb{R}^n\) si : \[\forall \varepsilon > 0,\; \exists N \in \mathbb{N},\; \forall k \geq N : \|x_k - \ell\| < \varepsilon\] On note \(x_k \to \ell\) ou \(\lim_{k\to\infty} x_k = \ell\).
Théorème — Convergence coordonnée par coordonnée
\(x_k = (x_k^{(1)}, \ldots, x_k^{(n)}) \to \ell = (\ell^{(1)}, \ldots, \ell^{(n)})\) si et seulement si pour chaque \(i\) : \(x_k^{(i)} \to \ell^{(i)}\) dans \(\mathbb{R}\).

3.2 Suites de Cauchy et complétude

Définition — Suite de Cauchy
\((x_k)\) est une suite de Cauchy si : \[\forall \varepsilon > 0,\; \exists N \in \mathbb{N},\; \forall p, q \geq N : \|x_p - x_q\| < \varepsilon\]
Théorème — Complétude de ℝⁿ
\(\mathbb{R}^n\) est complet : toute suite de Cauchy dans \(\mathbb{R}^n\) est convergente.
Preuve

Si \((x_k)\) est de Cauchy dans \(\mathbb{R}^n\), alors pour chaque coordonnée \(i\), la suite \((x_k^{(i)})\) est de Cauchy dans \(\mathbb{R}\) (car \(|x_p^{(i)} - x_q^{(i)}| \leq \|x_p - x_q\|_\infty \leq \|x_p - x_q\|\)). Par complétude de \(\mathbb{R}\), \(x_k^{(i)} \to \ell^{(i)}\). Donc \(x_k \to \ell = (\ell^{(1)},\ldots,\ell^{(n)})\).

□

3.3 Bolzano–Weierstrass

Théorème de Bolzano–Weierstrass
Toute suite bornée dans \(\mathbb{R}^n\) admet une sous-suite convergente.
Preuve (extraction diagonale)

Si \((x_k)\) est bornée dans \(\mathbb{R}^n\), la première composante \((x_k^{(1)})\) est bornée dans \(\mathbb{R}\), donc admet une sous-suite \((x_{\phi_1(k)})\) dont la première composante converge. De cette sous-suite, on extrait une sous-suite dont la deuxième composante converge. Après \(n\) étapes, la sous-suite \((x_{\phi_n(k)})\) converge en toutes les composantes.

□
⭐ Application IMC directe

Si \(f : K \to \mathbb{R}^m\) est continue et \(K\) est compact, et si \((y_k) = f(x_k)\) est une suite dans l'image, extraire une sous-suite de \((x_k)\) par B-W, puis utiliser la continuité.

Problème type : Montrer que l'image d'un compact par une application continue est compacte (et donc fermée et bornée).

3.4 Suites dans les fermés

Caractérisation séquentielle des fermés
\(F \subseteq \mathbb{R}^n\) est fermé \(\Longleftrightarrow\) pour toute suite \((x_k) \subseteq F\) avec \(x_k \to x\), on a \(x \in F\).
Exercices
Ex 3.1 Montrer que si \((x_k)\) est bornée et que toutes ses sous-suites convergentes ont la même limite \(\ell\), alors \(x_k \to \ell\). ▼
Indice : Raisonner par l'absurde : si \(x_k \not\to \ell\), il existe \(\varepsilon > 0\) et une sous-suite \((x_{k_j})\) avec \(\|x_{k_j} - \ell\| \geq \varepsilon\). Par B-W, extraire une sous-suite convergente de \((x_{k_j})\)... sa limite devrait être \(\ell\), contradiction.
Ex 3.2 ★★ (IMC 2019 style) Soit \(f : \mathbb{R}^n \to \mathbb{R}^n\) avec \(\|f(x) - f(y)\| \geq c\|x-y\|\) pour un \(c > 0\). Montrer que \(f\) est bijective. ▼
Indice : Injectivité est immédiate. Pour la surjectivité : montrer que l'image est ouverte (par le théorème de la fonction inverse) et fermée (si \(f(x_k) \to y\), la suite \((x_k)\) est de Cauchy car \(\|x_k - x_j\| \leq \frac{1}{c}\|f(x_k) - f(x_j)\|\)). Utiliser la connexité de \(\mathbb{R}^n\).
Étape 4 / 7

Compacité

4.1 Définition par recouvrements

Définition — Ensemble compact
\(K \subseteq \mathbb{R}^n\) est compact si de tout recouvrement ouvert de \(K\), on peut extraire un sous-recouvrement fini : \[ \text{Si } K \subseteq \bigcup_{i \in I} U_i \text{ (ouverts)},\quad \exists \text{ fini } J \subseteq I : K \subseteq \bigcup_{i \in J} U_i \]

4.2 Le théorème de Heine–Borel

Théorème de Heine–Borel (caractérisation dans ℝⁿ)
Pour \(K \subseteq \mathbb{R}^n\), les assertions suivantes sont équivalentes :
  1. \(K\) est compact
  2. \(K\) est fermé et borné
  3. \(K\) est séquentiellement compact : toute suite dans \(K\) admet une sous-suite convergente dans \(K\)
Preuve des implications clés

(2) ⟹ (3) : Soit \((x_k) \subseteq K\). \(K\) borné ⟹ \((x_k)\) bornée ⟹ par B-W, sous-suite convergente \(x_{k_j} \to x\). \(K\) fermé ⟹ \(x \in K\). ✓

(3) ⟹ (2) : Si \(K\) n'est pas borné, on construit \((x_k)\) avec \(\|x_k\| \geq k\), pas de sous-suite convergente. Si \(K\) n'est pas fermé, il existe \(x_k \in K\) avec \(x_k \to x \notin K\), toute sous-suite converge vers \(x \notin K\).

(3) ⟹ (1) : Supposer (1) faux : il existe un recouvrement ouvert sans sous-recouvrement fini. On construit une suite sans sous-suite convergente dans \(K\) — contradiction.

□

4.3 Propriétés des compacts

Propriétés fondamentales
  • Tout fermé inclus dans un compact est compact.
  • Toute intersection de compacts (non vide) est compacte.
  • Toute union finie de compacts est compacte.
  • L'image d'un compact par une application continue est compacte.
  • Si \(K\) est compact et \(f : K \to \mathbb{R}\) continue, alors \(f\) est bornée et atteint ses bornes (théorème des bornes atteintes).
⭐ Technique IMC — Compacité pour les extrema

Pour montrer qu'une fonction continue atteint son maximum sur un ensemble \(E\), montrer que \(E\) est compact (fermé et borné). Cette technique résout une grande variété de problèmes d'optimisation.

Exemple : "Trouver le point de \(E = \{(x,y) : x^2+y^2 \leq 1\}\) maximisant \(f(x,y) = 2x+3y\)." \(E\) est compact, \(f\) continue, donc le max existe — ici sur le bord, à trouver par Lagrange.

4.4 Compacité et suites de Cauchy

Théorème
Tout compact est complet (toute suite de Cauchy dans \(K\) converge dans \(K\)).
Théorème — Continuité uniforme sur les compacts (Heine)
Toute fonction continue sur un compact \(K\) est uniformément continue.
Exercices
Ex 4.1 Soit \(f : K \to K\) continue avec \(K\) compact non vide. Montrer que \(f\) a un point fixe si \(f\) est une contraction (i.e., \(d(f(x),f(y)) < d(x,y)\) pour \(x \neq y\)). ▼
Indice : Considérer \(g(x) = d(x, f(x))\), continue sur le compact \(K\). Elle atteint son minimum en un point \(x^*\). Montrer que \(f(x^*) = x^*\) : sinon, \(g(f(x^*)) = d(f(x^*), f(f(x^*))) < d(x^*, f(x^*)) = g(x^*)\), contredisant la minimalité.
Ex 4.2 ★★ (IMC) Montrer que si \(A, B \subseteq \mathbb{R}^n\) sont fermés et disjoints, avec \(A\) compact, alors \(d(A,B) = \inf_{a \in A, b \in B} \|a-b\| > 0\). ▼
Indice : La fonction \(f(a) = d(a, B) = \inf_{b \in B} \|a-b\|\) est continue sur \(A\). Par compacité de \(A\), elle atteint son minimum en \(a^*\). Si \(d(A,B) = 0\), alors \(d(a^*, B) = 0\), donc \(a^* \in \bar{B} = B\). Contradiction avec \(A \cap B = \emptyset\).
Étape 5 / 7

Connexité

5.1 Connexité

Définition — Ensemble connexe
\(E \subseteq \mathbb{R}^n\) est connexe s'il n'existe pas de partition \(E = U \cup V\) avec \(U, V\) ouverts dans \(E\), non vides et disjoints.

Équivalent : \(E\) est connexe si et seulement si les seuls sous-ensembles de \(E\) qui sont à la fois ouverts et fermés dans \(E\) sont \(\emptyset\) et \(E\) lui-même.

Théorème fondamental
\(E \subseteq \mathbb{R}\) est connexe \(\Longleftrightarrow\) \(E\) est un intervalle.
Théorème des valeurs intermédiaires (version topologique)
Si \(f : E \to \mathbb{R}\) est continue et \(E\) est connexe, alors \(f(E)\) est connexe (donc un intervalle). En particulier, si \(f(a) < k < f(b)\), il existe \(c\) tel que \(f(c) = k\).

5.2 Connexité par arcs

Définition — Connexité par arcs
\(E \subseteq \mathbb{R}^n\) est connexe par arcs si pour tout \(x, y \in E\), il existe un chemin continu \(\gamma : [0,1] \to E\) avec \(\gamma(0) = x\) et \(\gamma(1) = y\).
Théorème — Relation entre les deux notions
  • Connexe par arcs \(\Rightarrow\) connexe.
  • La réciproque est fausse en général.
  • Si \(E\) est ouvert dans \(\mathbb{R}^n\), alors : connexe \(\Leftrightarrow\) connexe par arcs.
Exemple — Le peigne topologique (connexe mais pas par arcs)
\(E = \{0\} \times [0,1] \cup \bigcup_{n=1}^\infty \left\{\frac{1}{n}\right\} \times [0,1]\) dans \(\mathbb{R}^2\) est connexe mais n'est pas connexe par arcs.
⭐ Techniques IMC avec la connexité

Technique 1 — Image constante : Si \(f : E \to \mathbb{Z}\) est continue et \(E\) est connexe, alors \(f\) est constante (car \(\mathbb{Z}\) est discret).

Technique 2 — Dichotomie ouvert/fermé : Pour montrer \(E = A\), montrer que \(A\) est non vide, ouvert et fermé dans \(E\) connexe.

Technique 3 — Chemin : Pour montrer qu'un ouvert de \(\mathbb{R}^n\) est connexe, relier deux points par un chemin polygonal.

5.3 Composantes connexes

Définition — Composantes connexes
Une composante connexe de \(E\) est un sous-ensemble connexe maximal de \(E\). Les composantes connexes forment une partition de \(E\) en fermés de \(E\).
Exercices
Ex 5.1 ★★ (style IMC) Soit \(f : \mathbb{R}^n \to \mathbb{R}^n\) continue avec \(f \circ f = \text{id}\). Montrer que l'ensemble des points fixes de \(f\) est non vide. (Prendre \(n=1\) pour commencer.) ▼
Indice : Pour \(n=1\) : poser \(g(x) = f(x) - x\). Soit \(a\) quelconque. Alors \(g(a) = f(a) - a\) et \(g(f(a)) = f(f(a)) - f(a) = a - f(a) = -g(a)\). Donc \(g(a)\) et \(g(f(a))\) sont de signes opposés, par TVI il existe \(c\) entre \(a\) et \(f(a)\) avec \(g(c) = 0\).
Ex 5.2 ★ Montrer que \(\text{GL}_n(\mathbb{R})\) est connexe par arcs si \(n\) est impair, mais a deux composantes connexes pour tout \(n\). ▼
Indice : Les deux composantes sont \(\{M : \det M > 0\}\) et \(\{M : \det M < 0\}\) (le déterminant est continu, donc chaque composante est ouverte et fermée dans \(\text{GL}_n(\mathbb{R})\)). Pour la connexité par arcs de chaque composante, utiliser la décomposition \(A = QR\) (QR decomposition) et les homotopies entre matrices.
Étape 6 / 7

Continuité et Topologie

6.1 Caractérisations équivalentes de la continuité

Théorème — Équivalences fondamentales
Pour \(f : \mathbb{R}^n \to \mathbb{R}^m\), les assertions suivantes sont équivalentes :
  1. \(f\) est continue en tout point de \(\mathbb{R}^n\) (définition \(\varepsilon\)-\(\delta\))
  2. Pour tout ouvert \(V \subseteq \mathbb{R}^m\), l'image réciproque \(f^{-1}(V)\) est ouverte dans \(\mathbb{R}^n\)
  3. Pour tout fermé \(F \subseteq \mathbb{R}^m\), l'image réciproque \(f^{-1}(F)\) est fermée dans \(\mathbb{R}^n\)
  4. Pour toute suite \(x_k \to x\), on a \(f(x_k) \to f(x)\)
⭐ Pourquoi (2) est la définition la plus puissante à l'IMC

La caractérisation (2) permet de montrer qu'un ensemble est ouvert ou fermé sans calcul, juste par une équation. Exemples :

  • \(\{x : f(x) > 0\} = f^{-1}(]0,+\infty[)\) est ouvert si \(f\) est continue
  • \(\{x : f(x) = 0\}\) est fermé si \(f\) est continue
  • \(\{A \in \mathcal{M}_n : \text{tr}(A) = 0\}\) est fermé (trace = application linéaire, donc continue)

6.2 Continuité uniforme

Définition — Continuité uniforme
\(f : E \to \mathbb{R}^m\) est uniformément continue si : \[\forall \varepsilon > 0,\; \exists \delta > 0,\; \forall x, y \in E : \|x-y\| < \delta \Rightarrow \|f(x)-f(y)\| < \varepsilon\] (Le \(\delta\) ne dépend pas du point \(x\).)
Théorème de Heine — Continuité uniforme sur les compacts
Si \(f : K \to \mathbb{R}^m\) est continue et \(K\) est compact, alors \(f\) est uniformément continue.
Preuve par Bolzano–Weierstrass

Supposons que \(f\) ne soit pas uniformément continue : il existe \(\varepsilon_0 > 0\) et des suites \((x_k), (y_k) \subseteq K\) avec \(\|x_k - y_k\| < \frac{1}{k}\) mais \(\|f(x_k) - f(y_k)\| \geq \varepsilon_0\). Par B-W, extraire \(x_{k_j} \to x \in K\). Alors aussi \(y_{k_j} \to x\). Par continuité : \(f(x_{k_j}) \to f(x)\) et \(f(y_{k_j}) \to f(x)\). Donc \(\|f(x_{k_j}) - f(y_{k_j})\| \to 0\), contradiction.

□

6.3 Homéomorphismes

Définition — Homéomorphisme
\(f : E \to F\) est un homéomorphisme si \(f\) est bijective, continue, et \(f^{-1}\) est continue. \(E\) et \(F\) sont alors homéomorphes et ont les mêmes propriétés topologiques.
Exemples
  • \(]0,1[\) et \(\mathbb{R}\) sont homéomorphes via \(x \mapsto \tan(\pi x - \pi/2)\).
  • \(\mathbb{R}^n\) et la boule ouverte \(B(0,1)\) sont homéomorphes via \(x \mapsto \frac{x}{1+\|x\|}\).
  • Le cercle \(S^1\) et l'intervalle \([0,1]\) ne sont pas homéomorphes (l'un est connexe par arcs, l'autre l'est aussi, mais l'un est simplement connexe et pas l'autre — différence en topologie algébrique).
Exercices
Ex 6.1 Montrer que \(f : [0,1] \to [0,1]\) continue implique l'existence d'un point fixe \(f(x_0) = x_0\). ▼
Indice : Appliquer le TVI à \(g(x) = f(x) - x\). On a \(g(0) = f(0) - 0 \geq 0\) et \(g(1) = f(1) - 1 \leq 0\). Donc \(g\) s'annule. C'est le théorème du point fixe de Brouwer en dimension 1 !
Ex 6.2 ★★ Soit \(K\) compact et \(f : K \to K\) une isométrie (i.e., \(d(f(x),f(y)) = d(x,y)\)). Montrer que \(f\) est surjective. ▼
Indice : Supposer \(f(K) \subsetneq K\) : il existe \(x_0 \in K \setminus f(K)\). Construire la suite \(x_0, x_1 = f(x_0), x_2 = f(x_1), \ldots\). Pour \(i > j \geq 1\), \(d(x_i, x_j) = d(f^{i-1}(x_1), f^{j-1}(x_1))\). En fait, montrer que \(d(x_k, x_j) \geq d(x_0, f(K)) > 0\) pour \(k \neq j\), contradiction avec B-W.

Grands Théorèmes pour l'IMC

Cette étape regroupe les résultats les plus souvent invoqués dans les solutions de l'IMC, avec les stratégies pour les appliquer efficacement.

7.1 Théorème du point fixe de Brouwer

Théorème de Brouwer
Toute application continue \(f : \bar{B}^n \to \bar{B}^n\) (de la boule fermée dans elle-même) possède un point fixe : il existe \(x^* \in \bar{B}^n\) tel que \(f(x^*) = x^*\).
⭐ Cas \(n=1\) et preuve IMC-level

Pour \(n=1\) : \(f : [-1,1] \to [-1,1]\) continue. Poser \(g(x) = f(x) - x\). Alors \(g(-1) = f(-1)+1 \geq 0\) et \(g(1) = f(1)-1 \leq 0\). Par TVI, \(g(c)=0\) i.e. \(f(c) = c\). ✓

Pour \(n \geq 2\) : la preuve utilise soit l'homologie soit un argument de rétraction. À l'IMC, on demande souvent des cas particuliers réductibles à \(n=1\).

7.2 Théorème des applications ouvertes et fermées

Théorème
Soit \(f : K \to \mathbb{R}^m\) continue avec \(K\) compact. Alors :
  • \(f\) est une application fermée : l'image de tout fermé de \(K\) est fermée.
  • En particulier, \(f(K)\) est compact (fermé et borné).
  • Si de plus \(f\) est bijective, alors \(f^{-1}\) est continue (i.e., \(f\) est un homéomorphisme).

7.3 Théorème de Baire

Théorème de Baire (version ℝⁿ)
\(\mathbb{R}^n\) est un espace de Baire : toute intersection dénombrable d'ouverts denses est dense. Équivalemment, \(\mathbb{R}^n\) ne peut pas s'écrire comme une union dénombrable d'ensembles d'intérieur vide (nulle part denses).
⭐ Application IMC de Baire

Problème type : Montrer que si \(f : \mathbb{R} \to \mathbb{R}\) est continue et pour tout \(x\), il existe \(n \in \mathbb{N}\) avec \(f^{(n)}(x) = 0\) (la dérivée \(n\)-ième s'annule en \(x\)), alors \(f\) est un polynôme.

Idée : Poser \(F_n = \{x : f^{(n)}(x) = 0\}\) fermé. Par hypothèse, \(\mathbb{R} = \bigcup_n F_n\). Par Baire, un \(F_N\) a un intérieur non vide, donc \(f^{(N)} = 0\) sur un intervalle, donc \(f\) est un polynôme de degré \(< N\).

7.4 Compacité et équicontinuité — Arzelà–Ascoli

Théorème d'Arzelà–Ascoli
Soit \((f_k)\) une suite de fonctions continues sur un compact \(K \subseteq \mathbb{R}^n\). Si \((f_k)\) est :
  • Uniformément bornée : \(\exists M, \forall k, \forall x : |f_k(x)| \leq M\)
  • Équicontinue : \(\forall \varepsilon > 0, \exists \delta > 0, \forall k, \forall x,y : \|x-y\| < \delta \Rightarrow |f_k(x)-f_k(y)| < \varepsilon\)
alors \((f_k)\) admet une sous-suite uniformément convergente sur \(K\).

Problèmes IMC niveau concours
★★★ Prob. 1 Soit \(f : \mathbb{R}^n \to \mathbb{R}^n\) continue et propre (\(f^{-1}(K)\) compact pour tout compact \(K\)). Montrer que \(f\) est une application fermée. ▼
Indice : Soit \(F \subseteq \mathbb{R}^n\) fermé, et \((y_k) \subseteq f(F)\) avec \(y_k \to y\). On a \(y_k \in f(F)\), donc \(\exists x_k \in F\) avec \(f(x_k) = y_k\). L'ensemble \(\{y_k : k \geq 1\} \cup \{y\}\) est compact, donc par propreté, \(f^{-1}(\{y_k\} \cup \{y\})\) est borné. Les \(x_k\) sont dans un compact, extraire une sous-suite \(x_{k_j} \to x \in F\) (F fermé), d'où \(y = f(x) \in f(F)\).
★★★ Prob. 2 Soit \(f : [0,1] \to [0,1]\) continue avec \(f(0) = 0\) et \(f(1) = 1\). Montrer que pour tout \(n \geq 1\), il existe \(x_0\) avec \(f(x_0) - x_0 = \frac{1}{n}\) ou montrer que c'est faux. ▼
Indice : C'est vrai ! Poser \(g(x) = f(x) - x - \frac{1}{n}\). Alors \(g(0) = -\frac{1}{n} < 0\) et \(g(1) = \frac{n-1}{n} > 0\) (pour \(n \geq 2\)). Par TVI, \(g\) s'annule. Pour \(n=1\) : \(g(0) = -1 < 0\) et \(g(1) = 0\) — TVI donne le point en \(x=1\) ou chercher autrement. L'énoncé complet dit : pour tout entier \(n \geq 1\), il existe \(x\) avec \(f(x) = x + \frac{1}{n}\).
★★★ Prob. 3 Soit \(A \in \mathcal{M}_n(\mathbb{R})\) une matrice symétrique définie positive. Montrer que \(\{x \in \mathbb{R}^n : x^T A x \leq 1\}\) est compact. ▼
Indice : L'ensemble est fermé (image réciproque de \(]-\infty, 1]\) par la fonction continue \(x \mapsto x^T A x\)). Pour la bornitude : \(A\) symétrique définie positive ⟹ toutes ses valeurs propres \(\lambda_i > 0\) ⟹ \(x^T A x \geq \lambda_{\min} \|x\|^2\). Donc si \(x^T A x \leq 1\), alors \(\|x\|^2 \leq \frac{1}{\lambda_{\min}}\).
