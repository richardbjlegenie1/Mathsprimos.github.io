Chapitre I

Fondements des Inégalités

1.1 — Propriétés de l'ordre sur ℝ

Toute inégalité repose sur les propriétés fondamentales de l'ordre total sur \(\mathbb{R}\).

Théorème — Propriétés de base

Pour tous réels \(a, b, c\) :

T
Transitivité : \(a \le b\) et \(b \le c \Rightarrow a \le c\).
+
Addition : \(a \le b \Rightarrow a + c \le b + c\).
×
Multiplication : si \(c > 0\), \(a \le b \Rightarrow ac \le bc\). Si \(c < 0\), l'inégalité se renverse.
Attention

La multiplication par un négatif renverse le signe — erreur très fréquente en concours !

1.2 — Valeur absolue et distance

Inégalité triangulaire
$$|a + b| \le |a| + |b|, \qquad \big||a| - |b|\big| \le |a - b|$$
▶ Preuve
1
On a \(-|a| \le a \le |a|\) et \(-|b| \le b \le |b|\).
2
En additionnant : \(-(|a|+|b|) \le a+b \le |a|+|b|\).
3
Par définition de la valeur absolue : \(|a+b| \le |a|+|b|\). \(\quad\square\)
Application IMC

Montrer que pour tout polynôme \(P\) à coefficients réels et tout \(z \in \mathbb{C}\) avec \(|z| \le 1\) :

$$|P(z)| \le \sum_{k=0}^{n} |a_k|$$

Solution : par inégalité triangulaire itérée, \(|P(z)| = \left|\sum a_k z^k\right| \le \sum |a_k| |z|^k \le \sum |a_k|\). \(\square\)

1.3 — Inégalité de Bernoulli

Théorème de Bernoulli
$$(1+x)^n \ge 1 + nx \qquad \forall x \ge -1,\; n \in \mathbb{N}$$
▶ Preuve par récurrence
1
Base : \(n=1\) : \((1+x)^1 = 1+x \ge 1+x\). ✓
2
Hérédité : supposer vrai au rang \(n\). Alors \((1+x)^{n+1} = (1+x)^n(1+x) \ge (1+nx)(1+x)\) (car \(1+x \ge 0\)).
3
Développer : \((1+nx)(1+x) = 1 + (n+1)x + nx^2 \ge 1+(n+1)x\). \(\square\)
✦ ✦ ✦

1.4 — Technique de la carrée positive

Le carré d'un réel est toujours positif. Ce fait élémentaire est à la base de nombreuses preuves.

Lemme fondamental
$$a^2 \ge 0 \quad \Longrightarrow \quad \frac{a+b}{2} \ge \sqrt{ab} \quad (a,b \ge 0)$$
▶ Preuve

Équivalent à \((\sqrt{a}-\sqrt{b})^2 \ge 0\), qui est vrai, avec égalité ssi \(a=b\). \(\square\)

Chapitre II

Les Grandes Inégalités Classiques

2.1 — AM-GM (Arithmétique–Géométrique)

Théorème — Inégalité AM-GM

Pour \(a_1, \ldots, a_n \ge 0\) :

$$\frac{a_1 + a_2 + \cdots + a_n}{n} \;\ge\; \sqrt[n]{a_1 a_2 \cdots a_n}$$

Égalité si et seulement si \(a_1 = a_2 = \cdots = a_n\).

Preuve — Méthode de Cauchy (avant-arrière)
▶ Dérouler la preuve complète
1
Base : \(n=2\) : \((\sqrt{a_1}-\sqrt{a_2})^2 \ge 0 \Rightarrow a_1+a_2 \ge 2\sqrt{a_1 a_2}\).
2
Pas en avant : si vrai pour \(n\), prouver pour \(2n\) en groupant les termes par paires.
3
Pas en arrière : si vrai pour \(n\), vrai pour \(n-1\) en posant \(a_n = \frac{a_1+\cdots+a_{n-1}}{n-1}\).
4
Ces deux passes couvrent tout \(\mathbb{N}\). \(\square\)
Exemple IMC classique

Montrer que pour \(x > 0\) : \(\;x + \dfrac{1}{x} \ge 2\).

Par AM-GM : \(\dfrac{x + 1/x}{2} \ge \sqrt{x \cdot \frac{1}{x}} = 1\). Égalité en \(x = 1\). \(\square\)

✦

2.2 — Cauchy-Schwarz

Théorème — Cauchy-Schwarz (forme discrète)
$$\left(\sum_{i=1}^n a_i b_i\right)^2 \;\le\; \left(\sum_{i=1}^n a_i^2\right)\left(\sum_{i=1}^n b_i^2\right)$$

Égalité ssi \((a_i)\) et \((b_i)\) sont proportionnels.

Preuve — Lagrange / discriminant
▶ Preuve par polynôme

Considérer \(f(t) = \sum (a_i t + b_i)^2 \ge 0\). C'est un polynôme du second degré en \(t\) :

$$f(t) = \underbrace{\left(\sum a_i^2\right)}_{A} t^2 + 2\underbrace{\left(\sum a_i b_i\right)}_{B} t + \underbrace{\left(\sum b_i^2\right)}_{C}$$

Comme \(f(t) \ge 0\) pour tout \(t\), le discriminant est négatif : \(4B^2 - 4AC \le 0\), soit \(B^2 \le AC\). \(\square\)

Forme de Engel (ou Titu)

Une variante très utile en IMC :

$$\frac{a_1^2}{b_1} + \frac{a_2^2}{b_2} + \cdots + \frac{a_n^2}{b_n} \;\ge\; \frac{(a_1 + \cdots + a_n)^2}{b_1 + \cdots + b_n}$$

pour \(b_i > 0\). S'obtient par Cauchy-Schwarz avec \(x_i = a_i/\sqrt{b_i}\) et \(y_i = \sqrt{b_i}\).

✦

2.3 — Inégalités de Hölder et Minkowski

Inégalité de Hölder

Pour \(p, q > 1\) avec \(\dfrac{1}{p} + \dfrac{1}{q} = 1\) :

$$\sum_{i=1}^n |a_i b_i| \;\le\; \left(\sum_{i=1}^n |a_i|^p\right)^{1/p} \left(\sum_{i=1}^n |b_i|^q\right)^{1/q}$$

Cauchy-Schwarz est le cas \(p = q = 2\).

Inégalité de Minkowski

Pour \(p \ge 1\) :

$$\left(\sum_{i=1}^n |a_i + b_i|^p\right)^{1/p} \;\le\; \left(\sum_{i=1}^n |a_i|^p\right)^{1/p} + \left(\sum_{i=1}^n |b_i|^p\right)^{1/p}$$

C'est l'inégalité triangulaire dans \(\ell^p\).

Conjugués de Hölder — à mémoriser
\(p\)\(q\) (conjugué)Application typique
\(2\)\(2\)Cauchy-Schwarz
\(3\)\(3/2\)Sommes cubiques
\(4\)\(4/3\)Puissances 4
\(\infty\)\(1\)\(\max \cdot \ell^1\)
✦

2.4 — Inégalité des moyennes de puissances (Power Mean)

Théorème

La moyenne de puissance d'ordre \(r\) est \(M_r = \left(\dfrac{\sum a_i^r}{n}\right)^{1/r}\). Alors pour \(s < r\) :

$$M_s \;\le\; M_r$$

Cas particuliers : \(M_{-\infty} \le M_{-1} \le M_0 \le M_1 \le M_2 \le M_{+\infty}\), i.e. min ≤ harmonique ≤ géométrique ≤ arithmétique ≤ quadratique ≤ max.

Chapitre III

Convexité & Inégalité de Jensen

3.1 — Fonctions convexes

Définition

Une fonction \(f : I \to \mathbb{R}\) est convexe si pour tout \(x, y \in I\) et \(\lambda \in [0,1]\) :

$$f(\lambda x + (1-\lambda)y) \;\le\; \lambda f(x) + (1-\lambda)f(y)$$

Géométriquement : la corde entre deux points est au-dessus du graphe.

Critère de convexité

Si \(f\) est deux fois dérivable, alors :

$$f \text{ convexe} \iff f''(x) \ge 0 \quad \forall x \in I$$
Fonction\(f''(x)\)Convexe sur
\(e^x\)\(e^x > 0\)\(\mathbb{R}\)
\(x^2\)\(2 > 0\)\(\mathbb{R}\)
\(-\ln x\)\(1/x^2 > 0\)\((0,+\infty)\)
\(x^p\) (\(p \ge 1\))\(p(p-1)x^{p-2} \ge 0\)\([0,+\infty)\)
\(\ln x\) (concave)\(-1/x^2 < 0\)\((0,+\infty)\)

3.2 — Inégalité de Jensen

Théorème de Jensen

Si \(f\) est convexe sur \(I\) et \(\lambda_1, \ldots, \lambda_n \ge 0\) avec \(\sum \lambda_i = 1\), alors :

$$f\!\left(\sum_{i=1}^n \lambda_i x_i\right) \;\le\; \sum_{i=1}^n \lambda_i f(x_i)$$

Si \(f\) est concave, l'inégalité se renverse.

Preuve par récurrence
▶ Dérouler
1
Base \(n=2\) : c'est la définition de la convexité.
2
Hérédité : Poser \(\Lambda = \sum_{i=1}^{n-1}\lambda_i = 1 - \lambda_n\). Écrire \(\sum_{i=1}^n \lambda_i x_i = \Lambda \cdot \bar{x} + \lambda_n x_n\) où \(\bar{x} = \sum_{i=1}^{n-1}\frac{\lambda_i}{\Lambda}x_i\).
3
Par convexité : \(f(\Lambda \bar{x} + \lambda_n x_n) \le \Lambda f(\bar{x}) + \lambda_n f(x_n)\). Puis appliquer l'hypothèse de récurrence à \(f(\bar{x})\). \(\square\)
Application — Preuve de AM-GM via Jensen

Appliquer Jensen à \(f = -\ln\) (convexe) avec \(\lambda_i = 1/n\) :

$$-\ln\!\left(\frac{\sum a_i}{n}\right) \le -\frac{\sum \ln a_i}{n} = -\frac{\ln(\prod a_i)}{n}$$

D'où \(\dfrac{\sum a_i}{n} \ge \left(\prod a_i\right)^{1/n}\). \(\square\)

✦

3.3 — Inégalité de Karamata (majoration)

Théorème de Karamata

Si \(\mathbf{x} = (x_1, \ldots, x_n)\) majore \(\mathbf{y} = (y_1,\ldots, y_n)\) (noté \(\mathbf{x} \succ \mathbf{y}\)) et si \(f\) est convexe, alors :

$$\sum_{i=1}^n f(x_i) \;\ge\; \sum_{i=1}^n f(y_i)$$

On dit \(\mathbf{x} \succ \mathbf{y}\) si les sommes partielles décroissantes de \(\mathbf{x}\) dominent celles de \(\mathbf{y}\) et \(\sum x_i = \sum y_i\).

Exemple typique IMC

Pour \(a+b+c = \pi\) (triangle), montrer \(\sin a + \sin b + \sin c \le \dfrac{3\sqrt{3}}{2}\).

Solution : \(\sin\) est concave sur \([0,\pi]\). Par Jensen avec \(\lambda_i=1/3\) :

$$\frac{\sin a + \sin b + \sin c}{3} \le \sin\!\left(\frac{a+b+c}{3}\right) = \sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}$$
Chapitre IV

Techniques Avancées pour l'IMC

4.1 — Méthode SOS (Sum of Squares)

Exprimer la différence LHS − RHS comme une somme de carrés (non-négatifs).

Exemple

Prouver : \(a^2 + b^2 + c^2 \ge ab + bc + ca\).

$$a^2+b^2+c^2 - ab - bc - ca = \tfrac{1}{2}\left[(a-b)^2 + (b-c)^2 + (c-a)^2\right] \ge 0. \quad\square$$
Stratégie SOS en compétition
1
Calculer \(D = \text{LHS} - \text{RHS}\).
2
Chercher une décomposition \(D = \sum \alpha_{ij}(x_i - x_j)^2\) avec \(\alpha_{ij} \ge 0\).
3
Identifier le cas d'égalité : il correspond aux \((x_i - x_j) = 0\) pour les \(\alpha_{ij} > 0\).
✦

4.2 — Tangent Line Trick (Droite tangente)

Principe

Si \(f\) est convexe, la tangente en tout point est sous la courbe :

$$f(x) \;\ge\; f(a) + f'(a)(x-a) \qquad \forall x$$

On choisit \(a\) au point d'égalité pour obtenir une borne linéaire utile.

Exemple — Inégalité exponentielle

Prouver : \(e^x \ge ex\) pour tout \(x \in \mathbb{R}\).

Tangente à \(f(x) = e^x\) en \(a = 1\) : \(f(x) \ge f(1) + f'(1)(x-1) = e + e(x-1) = ex\). \(\square\)

Plus généralement : pour prouver \(\sum f(x_i) \ge C\), trouver \(m\) tel que \(f(x) \ge mx + b\) et la somme devienne triviale.

✦

4.4 — Inégalités intégrales

Jensen intégral
$$f\!\left(\frac{1}{b-a}\int_a^b g(x)\,dx\right) \;\le\; \frac{1}{b-a}\int_a^b f(g(x))\,dx$$

pour \(f\) convexe et \(g\) intégrable.

Cauchy-Schwarz intégral
$$\left(\int_a^b f(x)g(x)\,dx\right)^2 \;\le\; \int_a^b f(x)^2\,dx \cdot \int_a^b g(x)^2\,dx$$
Application — Borne sur une intégrale

Montrer que \(\displaystyle\int_0^1 e^{x^2}\,dx \le e\).

Par convexité de \(e^t\) et Jensen : \(e^{x^2} \le e^x\cdot 1 + e^0\cdot(1-1)\)… En fait on majore \(x^2 \le x\) sur \([0,1]\) donc \(e^{x^2} \le e^x\), et \(\int_0^1 e^x\,dx = e-1 < e\). \(\square\)

✦

4.5 — Méthode de Lagrange et optimisation

Principe en concours

Pour trouver le cas d'égalité (essentiel pour IMC), chercher le minimum de LHS−RHS sous la contrainte par Lagrange, vérifier que ce minimum est 0, identifier les valeurs correspondantes.

$$\nabla f = \lambda \nabla g \quad \text{(extremum sous contrainte } g=0\text{)}$$

En pratique : poser les dérivées partielles égales, résoudre, vérifier que c'est bien un minimum global.

Chapitre V

Problèmes d'Entraînement IMC

Ces problèmes sont organisés par difficulté croissante. Essayez chaque problème avant d'ouvrir l'indice.

Problème 01 ★ Niveau 1

Montrer que pour tous réels \(a, b, c > 0\) :

$$\frac{a}{b} + \frac{b}{c} + \frac{c}{a} \;\ge\; 3$$
AM-GM directement sur les trois termes. Le cas d'égalité est \(a=b=c\).
Problème 02 ★ Niveau 1

Pour \(x_1, \ldots, x_n > 0\) avec \(\sum x_i = 1\), montrer :

$$\sum_{i=1}^n \frac{1}{x_i} \;\ge\; n^2$$
Cauchy-Schwarz (forme Titu/Engel) : \(\sum \frac{1^2}{x_i} \ge \frac{(\sum 1)^2}{\sum x_i} = n^2\).
Problème 03 ★★ Niveau 2

Soit \(a,b,c \ge 0\) avec \(a+b+c = 1\). Prouver :

$$ab + bc + ca \;\le\; \frac{1}{3}$$
Utiliser \((a+b+c)^2 = a^2+b^2+c^2+2(ab+bc+ca)\) et \(a^2+b^2+c^2 \ge \frac{(a+b+c)^2}{3}\) (Cauchy-Schwarz).
Problème 04 ★★ Niveau 2

Montrer que pour \(n \ge 1\) et \(x_1, \ldots, x_n \in \mathbb{R}\) :

$$\left(\sum_{i=1}^n x_i\right)^2 \;\le\; n \sum_{i=1}^n x_i^2$$
Cauchy-Schwarz avec \(a_i = x_i\) et \(b_i = 1\). Ou bien : \(\sum x_i^2 - \frac{(\sum x_i)^2}{n} = \frac{1}{2n}\sum_{i,j}(x_i-x_j)^2 \ge 0\) (SOS).
Problème 05 ★★ Niveau 2

Pour \(f\) convexe sur \([a,b]\), prouver l'inégalité de Hadamard :

$$f\!\left(\frac{a+b}{2}\right) \;\le\; \frac{1}{b-a}\int_a^b f(x)\,dx \;\le\; \frac{f(a)+f(b)}{2}$$
Pour la borne droite : \(f(x) \le f(a)\frac{b-x}{b-a} + f(b)\frac{x-a}{b-a}\) par convexité, puis intégrer. Pour la borne gauche : Jensen intégral.
Problème 06 — Style IMC ★★★ Niveau 3

Soient \(a_1 \ge a_2 \ge \cdots \ge a_n > 0\). Prouver que pour tout entier \(k \le n\) :

$$\left(\sum_{i=1}^n a_i\right)\left(\sum_{i=1}^k \frac{1}{a_i}\right) \;\ge\; k^2$$
Cauchy-Schwarz : \(\left(\sum_{i=1}^n a_i\right)\left(\sum_{i=1}^k \frac{1}{a_i}\right) \ge \left(\sum_{i=1}^k \sqrt{a_i \cdot \frac{1}{a_i}}\right)^2 = k^2\). Attention à l'asymétrie des sommes !
Problème 07 — Style IMC ★★★ Niveau 3

Soit \(f : [0,1] \to \mathbb{R}\) continue et positive. Montrer :

$$\left(\int_0^1 f(x)\,dx\right)^2 \;\le\; \int_0^1 f(x)^2\,dx$$

et déterminer quand il y a égalité.

Cauchy-Schwarz intégral avec \(g \equiv 1\). Égalité ssi \(f\) est constante p.p.
