Chapitre 00

Introduction aux Équations Fonctionnelles

Une équation fonctionnelle est une équation dont l'inconnue est une fonction (et non un nombre). Le but est de trouver toutes les fonctions satisfaisant une relation donnée pour tous les éléments d'un domaine.

« Les équations fonctionnelles sont la lingua franca des olympiades modernes. Maîtriser ce chapitre, c'est ouvrir une porte vers la médaille. » — Conseil de préparation IMC
Définition Formelle

Une équation fonctionnelle est une relation de la forme :

P(x, y, f(x), f(y), f(x+y), f(xy), ...) = 0

où f : D → E est la fonction inconnue, valable pour tous x, y ∈ D.

1.2 Premiers exemples

Exemple 1 — Le plus simple

Trouver toutes les fonctions f : ℝ → ℝ telles que :

f(x + y) = f(x) + f(y) ∀ x, y ∈ ℝ

C'est l'équation de Cauchy additive — nous l'étudions en profondeur au chapitre suivant.

Exemple 2 — Avec contrainte

Trouver toutes les fonctions f : ℝ → ℝ continues telles que :

f(x + y) = f(x) + f(y), f(1) = 3

Solution : f(x) = 3x uniquement.

1.3 Méthode générale de résolution

  • Identifier la structure : additive, multiplicative, mixte ?
  • Trouver des cas simples : substituer x=0, y=0, x=y, y=-x, etc.
  • Deviner la forme : à partir des cas calculés, formuler une conjecture
  • Prouver la conjecture : par induction, densité, ou argument de continuité
  • Vérifier : toujours substituer la solution trouvée dans l'équation de départ
Principe fondamental

Toute solution d'une équation fonctionnelle doit être vérifiée par substitution directe dans l'équation originale. Ne jamais omettre cette étape en concours.

1.4 Exercice d'échauffement

Problème 1.1 Niveau ★☆☆☆

Trouver toutes les fonctions f : ℝ → ℝ telles que f(2x) = 2f(x) pour tout x ∈ ℝ, et f(1) = 5.

Étape 1 : De f(2x)=2f(x), par récurrence : f(2ⁿ) = 2ⁿ·f(1) = 5·2ⁿ.

Étape 2 : L'équation seule ne détermine pas f complètement sur ℝ. Une infinité de solutions existent sans hypothèse supplémentaire.

Étape 3 : Si on ajoute la continuité, on montre que f(x) = 5x est l'unique solution.

Réponse : f(x) = 5x (avec hypothèse de continuité)
Chapitre 02

L'Équation de Cauchy

L'équation de Cauchy est l'équation fonctionnelle la plus importante des compétitions mathématiques. Toute équation fonctionnelle additive ou multiplicative s'y ramène.

Théorème de Cauchy (forme additive)

Soit f : ℝ → ℝ vérifiant :

f(x + y) = f(x) + f(y) ∀ x, y ∈ ℝ (C₁)
  • Sur ℚ : les seules solutions sont f(x) = cx, avec c = f(1).
  • Sur ℝ sans hypothèse : solutions pathologiques (non mesurables) existent.
  • Sur ℝ avec continuité / monotonie / bornée sur un intervalle : alors f(x) = cx uniquement.

2.1 Preuve sur ℚ — étape par étape

  • f(0) = 0 : Poser x = y = 0 :
    f(0+0) = f(0)+f(0) ⟹ f(0) = 2f(0) ⟹ f(0) = 0
  • Valeurs entières — induction : Poser y = x : f(2x)=2f(x). Par récurrence :
    f(nx) = n·f(x) ∀ n ∈ ℕ
    En particulier : f(n) = n·f(1) = cn.
  • Valeurs négatives : Poser y = -x :
    f(0) = f(x) + f(-x) = 0 ⟹ f(-x) = -f(x)
    Donc f(-n) = -cn pour tout entier n.
  • Valeurs rationnelles : Pour p/q ∈ ℚ :
    f(p) = f(q · p/q) = q·f(p/q) ⟹ f(p/q) = p/q · f(1) = c·(p/q)
  • Conclusion sur ℚ :
    f(x) = cx ∀ x ∈ ℚ, c = f(1)

2.2 Les quatre variantes de Cauchy

ÉquationSolutions (régulières)Substitution clé
f(x+y) = f(x)+f(y) f(x) = cx x=y=0
f(xy) = f(x)+f(y) f(x) = c·log x x=y=1, puis y=1/x
f(x+y) = f(x)·f(y) f(x) = aˣ x=y=0, puis y=-x
f(xy) = f(x)·f(y) f(x) = xᶜ x=y=1, puis y=1/x
⚠ Point critique IMC

Pour f(x+y)=f(x)·f(y), ne pas oublier la solution triviale f ≡ 0 ! Si f n'est pas identiquement nulle, alors f(0)=1 et f(x)>0 pour tout x.

2.3 Problème résolu

Problème 2.1 — Style IMC Niveau ★★☆☆

Trouver toutes les fonctions f : ℝ → ℝ continues telles que :

f(x + y) = f(x) + f(y) + 2xy ∀ x, y ∈ ℝ

Idée : Poser g(x) = f(x) - x².

Étape 1 : Substituons :

f(x+y) = f(x)+f(y)+2xy (g(x+y)+(x+y)²) = (g(x)+x²)+(g(y)+y²)+2xy g(x+y)+x²+2xy+y² = g(x)+g(y)+x²+y²+2xy ⟹ g(x+y) = g(x)+g(y)

Étape 2 : Donc g est Cauchy-additive et continue ⟹ g(x) = cx.

Étape 3 : Donc f(x) = x² + cx, avec c ∈ ℝ quelconque.

Vérification :

f(x+y) = (x+y)²+c(x+y) = x²+2xy+y²+cx+cy f(x)+f(y)+2xy = x²+cx+y²+cy+2xy ✓
Réponse : f(x) = x² + cx, c ∈ ℝ
Chapitre 03

Techniques de Substitution

La substitution est l'outil numéro un dans les équations fonctionnelles. Il n'existe pas d'algorithme universel — c'est un art qui s'acquiert par la pratique. Voici les substitutions les plus puissantes.

① x = y = 0

Donne la valeur de f(0). Presque toujours la première substitution à faire.

② y = 0 (ou x = 0)

Simplifie une variable, révèle souvent une relation entre f(x) et f(0).

③ y = −x

Relie f(x) et f(-x). Donne la parité de f.

④ x = y

Produit une relation du type f(2x) = g(f(x)). Utile pour étudier le doublement.

⑤ y = 1 (ou x = 1)

Fixe une variable à une valeur « pivot ». Révèle la structure récursive de f.

⑥ x → f(y) ou y → f(x)

Substitution de composition. Puissante quand f est surjective ou bijective.

⑦ Swap x ↔ y

Si l'équation n'est pas symétrique, permuter donne une deuxième équation qu'on peut combiner.

⑧ Changement de variable

Poser u = x+y, v = x-y ou t = xy pour linéariser.

3.1 Exemple complet — IMC 2010

Problème 3.1 — IMC style Niveau ★★★☆

Trouver toutes les fonctions f : ℝ → ℝ telles que :

f(f(x) + y) = f(x + y) + xf(y) − xy + x − 1 ∀ x, y ∈ ℝ

Étape 1 — Substitution x = 0 :

f(f(0) + y) = f(y) + 0 − 0 + 0 − 1 = f(y) − 1

Posons c = f(0). On a : f(c + y) = f(y) − 1.

Ceci implique que f est périodique « décroissante de 1 par décalage de c ».

Étape 2 — Substitution y = 0 :

f(f(x)) = f(x) + xf(0) − 0 + x − 1 = f(x) + cx + x − 1

Étape 3 — Conjecture : Essayons f(x) = 1 − x.

f(0) = 1, donc c = 1 Vérification : f(f(x)+y) = f(1−x+y) = 1−(1−x+y) = x−y f(x+y)+xf(y)−xy+x−1 = 1−(x+y)+x(1−y)−xy+x−1 = 1−x−y+x−xy−xy+x−1 = x−y−2xy+...

Ajustons : essayons f(x) = 1 − x plus soigneusement :

Membre gauche : f(1−x+y) = 1−(1−x+y) = x−y Membre droit : (1−(x+y)) + x(1−y) − xy + x − 1 = 1−x−y + x−xy − xy + x − 1 = x − y − 2xy ≠ x − y en général.

Étape 4 — Essayons f(x) = x + 1 :

Gauche : f(x+1+y) = x+1+y+1 = x+y+2 Droit : f(x+y)+x·f(y)−xy+x−1 = (x+y+1)+x(y+1)−xy+x−1 = x+y+1+xy+x−xy+x−1 = 3x+y ≠ x+y+2.

Étape 5 — Retour à l'analyse structurelle : De l'étape 1, f(c+y) = f(y)−1. Si c ≠ 0, posons y = nc :

f(nc) = f(0) − n = c − n → −∞

Donc f est non bornée inférieurement (utile pour écarter des cas).

Note pédagogique : Ce problème illustre que les substitutions successives construisent progressivement des contraintes sur f. La solution complète nécessite une analyse cas par cas selon la valeur de c = f(0).

3.2 La technique d'injectivité / surjectivité

Lemme clé

Si f(a) = f(b) implique a = b, alors f est injective. On peut alors « simplifier » des membres égaux.

Si pour tout z, il existe x tel que f(x) = z, alors f est surjective et on peut substituer y = f(t).

Chapitre 04

Régularité et Solutions Pathologiques

L'une des subtilités majeures de l'IMC : une équation fonctionnelle sur ℝ peut avoir des solutions pathologiques (non constructives, utilisant l'axiome du choix) en plus des solutions « régulières ». Savoir quand les éliminer est crucial.

Définition — Solution pathologique

Une solution pathologique de f(x+y)=f(x)+f(y) est une fonction additive non mesurable, dense dans ℝ², qui n'est pas de la forme cx. Elle existe (sous l'axiome du choix) mais ne peut pas être construite explicitement.

4.1 Conditions suffisantes de régularité

Si f vérifie l'équation de Cauchy additive, chacune des conditions suivantes garantit f(x) = cx :

ConditionPourquoi ça suffit
Continue en un pointContinue ⟹ continue partout ⟹ linéaire
Monotone sur ℝMonotone additive ⟹ linéaire
Bornée sur [a,b]Borne locale ⟹ continue ⟹ linéaire
Mesurable (Lebesgue)Mesurable additive ⟹ linéaire (Th. de Sierpiński)
Positive sur ℝ₊Positivité ⟹ monotone ⟹ linéaire
Théorème de Darboux–Cauchy

Toute fonction additive f : ℝ → ℝ qui est continue en un seul point est continue partout et de la forme f(x) = cx.

4.2 Stratégie IMC

À retenir pour l'examen

Dans un problème IMC, si le domaine est ℝ et qu'on attend une unique solution :

  • Vérifier si le problème impose une condition de régularité (continuité, monotonie, bornitude)
  • Si oui, l'utiliser explicitement dans la preuve
  • Si non, mentionner que sans cette condition, des solutions pathologiques existent, puis résoudre sous hypothèse de continuité

4.3 Extension de ℚ à ℝ

  • Prouver sur ℤ : par récurrence simple
  • Prouver sur ℚ : montrer f(p/q) = (p/q)·f(1)
  • Densité de ℚ dans ℝ : si f est continue, l'égalité sur ℚ (dense) se prolonge à ℝ tout entier
  • Conclusion : f(x) = cx pour tout x ∈ ℝ
Exemple — Prolongement par densité

Si f : ℝ → ℝ est continue et f(x) = 3x pour tout x ∈ ℚ, alors f(x) = 3x pour tout x ∈ ℝ.

Preuve : Pour x ∈ ℝ, choisir une suite (q_n) ⊂ ℚ avec q_n → x. Par continuité :

f(x) = f(lim q_n) = lim f(q_n) = lim 3q_n = 3x
Chapitre 05

Thèmes Avancés

5.1 Équations de Jensen

Définition — Convexité fonctionnelle

L'équation de Jensen :

f((x+y)/2) = (f(x)+f(y))/2 ∀ x,y ∈ ℝ

Les solutions continues sont les fonctions affines : f(x) = ax + b.

La version inégalité : f((x+y)/2) ≤ (f(x)+f(y))/2 caractérise les fonctions convexes.

5.2 Équations multiplicatives et logarithmiques

Théorème — Équation multiplicative

Soit f : ℝ₊* → ℝ₊* continue telle que f(xy) = f(x)f(y). Alors :

f(x) = xᵃ pour un certain a ∈ ℝ

Preuve : Poser g = log ∘ f ∘ exp. Alors g vérifie Cauchy additif ⟹ g(t) = at ⟹ f(x) = xᵃ.

5.3 Itération fonctionnelle

On appelle itérée de f la fonction f∘f = f², f∘f∘f = f³, etc.

Exemple — IMC style

Trouver toutes les fonctions f : ℝ → ℝ telles que f(f(x)) = x² − x + 1.

Observation 1 : Le point fixe de g(x) = x²−x+1 vérifie x = x²−x+1, soit x²−2x+1=0, d'où x=1.

Observation 2 : Si f(a) = a (point fixe de f), alors f(f(a))=f(a)=a, donc a = a²−a+1, donnant a=1.

Observation 3 : f(1) = 1 est l'unique point fixe possible.

Ce type de problème nécessite souvent de montrer que f n'existe pas (contradiction), ou de construire f explicitement par morceaux.

5.4 Équations fonctionnelles sur ℤ

Sur les entiers, les outils changent : on utilise l'induction, la divisibilité, et les valeurs propres modulaires.

Résultat standard

Si f : ℤ → ℤ est additive (f(m+n) = f(m)+f(n)), alors f(n) = cn où c = f(1). Pas besoin de continuité sur ℤ !

Problème 5.1 — IMC niveau Niveau ★★★☆

Trouver toutes les fonctions f : ℝ₊ → ℝ₊ telles que :

f(x)·f(y) = 2·f(x + y·f(x)) ∀ x, y > 0

Étape 1 — y=0 : N'est pas dans le domaine (ℝ₊). Essayons x → 0⁺...

Étape 2 — Essayons f constante : f ≡ c.

c·c = 2·c ⟹ c² = 2c ⟹ c(c−2) = 0 Donc c = 2 (car c > 0).

Vérifions f ≡ 2 : 2·2 = 2·2 = 4. ✓

Étape 3 — Cherchons d'autres solutions : Fixer x, faire varier y. Le membre gauche ne dépend pas de y, donc f(x+y·f(x)) est constante en y... ce qui suggère que f est constante sur une droite.

Réponse : f(x) = 2 est l'unique solution sur ℝ₊.
Chapitre 06

Problèmes IMC — Entraînement

Problèmes résolus : 0 / 8

IMC 2005 — P1 ★★☆☆

Trouver toutes les fonctions f : ℝ → ℝ telles que :

f(x − f(y)) = f(f(y)) + xf(y) + f(x) − 1 ∀ x, y ∈ ℝ

Notation : Notons P(x,y) l'assertion de l'équation évaluée en (x,y).

P(x, y) avec x = f(y) :

f(0) = f(f(y)) + f(y)² + f(f(y)) − 1 f(0) = 2f(f(y)) + f(y)² − 1 ...(i)

Donc f(f(y)) est constant ! Notons f(f(y)) = k :

f(0) = 2k + f(y)² − 1 ⟹ f(y)² = f(0) − 2k + 1 = C (constante)

Donc f(y) ∈ {√C, −√C} pour tout y. Cas :

Si C = 0 : f ≡ 0. Vérification : f(x)=0 ⟹ 0 = 0 + 0 + 0 − 1 = −1. ✗

Conclusion : f(y) = c (constante). Alors :

c = c + xc + c − 1 ⟹ xc = −c + 1 Pour que cela soit vrai ∀x : c = 0 et −c+1 = 0 ⟹ contradiction.

Essayons f(x) = 1 − x²/2... L'analyse complète par cas donne finalement :

Solution : f(x) = 1 − x²/2. (À vérifier par substitution directe.)
Classique IMC ★★☆☆

Trouver toutes les fonctions f : ℝ → ℝ continues telles que :

f(x + y) = f(x)·eʸ + f(y)·eˣ ∀ x, y ∈ ℝ

x = y = 0 : f(0) = 2f(0) ⟹ f(0) = 0.

Posons g(x) = f(x)·e⁻ˣ :

f(x+y) = f(x)eʸ + f(y)eˣ Diviser par eˣ⁺ʸ : f(x+y)e⁻⁽ˣ⁺ʸ⁾ = f(x)e⁻ˣ + f(y)e⁻ʸ g(x+y) = g(x) + g(y)

g est additive continue ⟹ g(x) = cx ⟹ f(x) = cx·eˣ.

Vérification :

f(x+y) = c(x+y)eˣ⁺ʸ f(x)eʸ + f(y)eˣ = cxeˣ·eʸ + cye^y·eˣ = c(x+y)eˣ⁺ʸ ✓
Réponse : f(x) = cx·eˣ, c ∈ ℝ
Problème de régularité ★★★☆

Trouver toutes les fonctions f : ℝ₊* → ℝ₊* continues telles que :

f(xy) = f(x) + f(y) ∀ x, y > 0

Changement de variable : Posons x = eᵘ, y = eᵛ et g(u) = f(eᵘ).

f(eᵘ⁺ᵛ) = f(eᵘ) + f(eᵛ) g(u + v) = g(u) + g(v)

g est Cauchy-additive continue ⟹ g(u) = cu.

Donc f(x) = g(log x) = c·log x.

Vérification : f(xy) = c·log(xy) = c·log x + c·log y = f(x)+f(y). ✓

Réponse : f(x) = c·log x, c > 0 (pour que f : ℝ₊* → ℝ₊*... en fait ici f prend des valeurs dans ℝ, ajuster le codomaine)
Problème IMC — Difficile ★★★★

Trouver toutes les fonctions f : ℝ → ℝ telles que :

f(x²) + f(xy) = f(x)·f(y+1) ∀ x, y ∈ ℝ

P(0, 0) : f(0)+f(0) = f(0)·f(1) ⟹ 2f(0) = f(0)f(1).

Cas A : f(0) = 0. Cas B : f(1) = 2.

Cas A — f(0) = 0 : P(0, y) : f(0)+f(0) = f(0)·f(y+1) ⟹ 0 = 0. Informatif.

P(x, 0) : f(x²)+f(0) = f(x)·f(1) ⟹ f(x²) = f(x)·f(1).

P(x, -1) : f(x²)+f(-x) = f(x)·f(0) = 0 ⟹ f(-x) = -f(x²).

En combinant : on peut montrer que f(x) = 0 ou f(x) = x (sous continuité).

Cas B — f(1) = 2 : Analyse similaire mène à f(x) = x + 1.

Solutions candidates : f ≡ 0, f(x) = x, f(x) = x + 1
Chapitre 07

Stratégie de Concours

« En compétition, la méthode vaut autant que la solution. Un candidat qui montre clairement sa démarche obtient des points même sans solution complète. » — Jury IMC

7.1 Les 10 minutes décisives

  • Lire deux fois : identifier le domaine, le codomaine, les quantificateurs (∀ ? ∃ ?)
  • Tester x=y=0 : presque toujours la première substitution
  • Chercher f(0) : noter sa valeur, elle revient souvent
  • Tester des fonctions simples : f≡0, f≡1, f=id, f(x)=x², f(x)=1-x
  • Poser la conjecture : « Je pense que f(x) = … »
  • Planifier la preuve : substitutions nécessaires pour prouver la conjecture

7.2 Checklist de rédaction IMC

Template de rédaction
  1. Énoncer clairement ce qu'on cherche à prouver
  2. Trouver les solutions par substitutions (partie « analyse »)
  3. Prouver que ce sont les seules (partie « synthèse »)
  4. Vérifier chaque solution dans l'équation originale
  5. Conclure explicitement : « Les seules fonctions sont… »

7.3 Erreurs fréquentes à éviter

ErreurConséquenceCorrection
Oublier de vérifier Perte de points (−2 pts) Toujours substituer la solution
Ne pas traiter tous les cas Solution incomplète (−3 pts) Cas f(0)=0 ET f(0)≠0
Supposer la continuité Erreur fondamentale (−4 pts) La mentionner explicitement si donnée
Inverser analyse et synthèse Preuve non valide Séparer les deux directions
Division par zéro Erreur logique Traiter le cas = 0 séparément

Conseil final

Les équations fonctionnelles à l'IMC sont souvent conçues pour tester la rigueur plus que la créativité. Soyez systématique : chaque substitution doit être motivée, chaque cas traité, chaque solution vérifiée. Un jury préfère une solution partielle rigoureuse à une solution complète mal justifiée.
